# EcoSort — Stage 1 (Frontend Demo)

EcoSort is a beginner-friendly Data Structures and Algorithms project for organizing waste records.

## Stage 1 features
- Add a waste item, quantity, unit, and category
- View total records by category
- Search items and filter by category
- Sort item names A–Z or Z–A
- Remove one record or clear all records
- Save demo records in the browser using `localStorage`

## Run on Windows
1. Download and extract this folder.
2. Open `index.html` in Chrome or Edge.
3. Add a few waste items to test the page.

No installation is needed for Stage 1.

## Important
This first stage uses browser storage so you can learn the interface. The next stage will add a C backend and replace browser-only storage with backend-managed records. The category is selected manually in this stage.
